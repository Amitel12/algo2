אלגוריתם דייקסטרה

מתי משתמשים? בגרפים עם משקלים אי-שליליים (w ≥ 0).

סיבוכיות זמן:

  • גרף דליל: שימוש ב-Min-Heap ← O(E log V)
  • גרף צפוף: שימוש במערך ← O(V²)

while (Q is not empty) {

  u = ExtractMin(Q);

  for each v in adj[u] {

    // Relaxation:

    if (d[v] > d[u] + w(u,v)) {

      d[v] = d[u] + w(u,v);

      pi[v] = u;

    }

  }

}
