חוקים וסיבוכיות

מותר לשימוש רק בגרפים עם משקלים אי-שליליים (w ≥ 0).

סיבוכיות זמן:

  • עם Min-Heap: O(E log V)
  • עם מערך פשוט: O(V²)
d[src] = 0; // all other d[i] = INT_MAX // אתחול מרחקים
while (!isEmpty(Q)) { // כל עוד התור לא ריק
int u = extractMin(Q, d); // שליפת צומת עם מרחק מינימלי
for (Edge* e = adj[u]; e != NULL; e = e->next) { // מעבר על הרשימה המקושרת
int v = e->dest, w = e->weight; // חילוץ נתוני השכן
if (d[u] != INT_MAX && d[v] > d[u] + w) { // הגנה מ-Overflow ובדיקת שיפור
d[v] = d[u] + w; // עדכון מרחק
pi[v] = u; // שמירת אב
}
}
}
מקרא סימנים:
  • d - המרחק המינימלי מצומת המקור.
  • π - אב (Pi): הצומת הקודם במסלול.
  • S - קבוצת הצמתים שטופלו סופית.
  • w - משקל הצלע (מוצג על החצים).
