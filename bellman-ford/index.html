מאפיינים ומסקנות

  • תומך בגרפים עם משקלים שליליים.
  • מבוסס על תכנון דינמי (Tabulation).
  • מחשב מרחקים רק לצמתים שניתן להגיע אליהם מצומת המקור (השאר נשארים ∞).
  • אם קיים מעגל שלילי, אין מרחק קצר ביותר (כל מעבר נוסף מקטין את המסלול).

סיבוכיות זמן: O(|V||E|)

for each vertex v ∈ V: d[v] = ∞, π[v] = NIL // אתחול הגרף
d[s] = 0
for i = 1 to |V| - 1: // ריצה כמעט עד הקדקוד האחרון
for each edge (u, v) ∈ E: // מעבר על כל הקדקודים המקושרים
if d[u] + w(u,v) < d[v]: // הקלה (Relax)
d[v] = d[u] + w(u,v), π[v] = u // עדכון מסלול קצר יותר ושמירת צומת האב
// Step 3: check for negative-weight cycles
for each edge (u, v) ∈ E: // בדיקה של כל הצלעות
if d[u] + w(u,v) < d[v]: // אם תנאי זה מתקיים - יש מעגל שלילי אינסופי
return ERROR
