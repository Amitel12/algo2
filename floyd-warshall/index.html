אלגוריתם Floyd-Warshall

צעד 0/0

הערות ומסקנות

  • מציע פתרון לכל הזוגות בגרף (All-Pairs Shortest Path).
  • יכול להתמודד עם קשתות שליליות, אך רק כאשר אין מעגלים שליליים.
  • זיהוי מעגל שלילי: לאחר סיום, אם מתקבל ערך שלילי באלכסון הראשי ב-D.
  • מבוסס על תכנון דינמי (Dynamic Programming).
  • השורה $k$ והעמודה $k$ במטריצה משמשות כבסיס לחישובים ולא משתנות באיטרציה $k$.

סיבוכיות זמן: O(|V|³)

n ← rows[W] // מספר צמתים
D ← W // אתחול מרחקים
P ← INITIALIZE_PATH_MATRIX(W) // אתחול אבות
for k ← 1 to n // צומת מתווך k
for i ← 1 to n
for j ← 1 to n
if (dij > dik + dkj)
dij ← dik + dkj
pij ← pkj
return D
מקרא צבעים:
צומת מתווך ($k$)
צומת מקור ($i$)
צומת יעד ($j$)

מטריצות האלגוריתם

D(0) / Π(0)
  • שורה/עמודה תכלת: שורת/עמודת המתווך (k). לא משתנות באיטרציה.
  • תא צהוב/ירוק: התא הנבדק/מעודכן עכשיו d[i,j].
  • תאים כתומים: הערכים שמרכיבים את המסלול החדש d[i,k] + d[k,j].
